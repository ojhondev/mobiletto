# Mobiletto · Catálogo 2027 (protótipo)

Catálogo B2B com experiência de catálogo físico: páginas A4 que viram com arraste,
desenhos técnicos animados, troca de acabamentos, ambiente com pontos clicáveis e
lista de cotação montada "dobrando o canto" das páginas.

```bash
npm install
npm run dev -- -p 3017
```

Abra http://localhost:3017/catalogo
